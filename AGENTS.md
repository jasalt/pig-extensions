# Working rules

Implement `plan.md`; `pi-handoff.md` is historical evidence, not acceptance.
Use independent Go factories pinned to PiG SDK v0.3.1 and Go language floor 1.26.
Do not modify sibling repositories, install globally, publish, or migrate state.
Use isolated test homes and dummy credentials; no real alerts/reset redemption.
Commit coherent verified changes atomically (authorized by the current goal).
Preserve third-party licenses and record source hashes and behavior differences.
Do not count registration as functional evidence or text PTYs as graphics proof.
